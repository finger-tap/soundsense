# 声级计原理与闻声算法审核记录

> 2026-09-30 算法复审。背景:A 计权模式下环境噪音长期显示个位数 dB,
> C 计权比 A 高 6~7 dB,与真实环境(安静室内 LAeq ≈ 30~45 dB)明显不符。
> 本文从声级计(IEC 61672-1)的信号链路出发,给出问题定位、依据与修复方案。

## 1. 声级计的标准链路(IEC 61672-1)

```
麦克风 → 前置放大 → 频率计权网络(A/C/Z) → RMS 检波器(时间计权 F/S) → 对数显示
                └─ 声校准在此进行(灵敏度 = 数字值 ↔ Pa 的换算系数)
```

四个环节,闻声对应实现:

| 环节 | 标准要求 | 闻声实现 | 审核结论 |
|---|---|---|---|
| 频率计权 | IEC 61672-1 附录 A 解析曲线,A(f)=20log10(Ra(f)/Ra(1000)) | `WeightingFilter` 时域 IIR:预畸变双线性极点 + 高频补偿,1 kHz 归一化 | ✅ 正确(44.1/48/96 kHz 与解析曲线最大偏差 <0.05 dB) |
| RMS 检波 | 对**均方声压(能量域)**做一阶指数平均,τ_F=125 ms,τ_S=1 s | 曾在 **dB 域**平滑(α=0.2)→ 已改为能量域 EMA | ✅ 已修复 |
| Leq | 10·log10( mean(10^(L/10)) ),纯能量平均,与 F/S 无关 | 核心对计权均方值按真实 hop 时长积分;停止时排空 tail | ✅ |
| 绝对标定 | 94.0 dB / 1 kHz 声校准器(IEC 60942)定灵敏度 | 曾默认 +93 dB,无依据 → 见下文 | ❌ 主因,已修复 |

## 2. 主因:校准偏移 +93 比真实值低约 30 dB

### 2.1 dBFS ↔ SPL 换算的物理依据

数字 MEMS 麦克风(苹果供应商 Knowles/Infineon 等)行业惯例:

- 灵敏度以 **94 dB SPL @ 1 kHz 正弦**为参考;
- 典型规格 −26 dBFS@94 dB(**峰值**参考),即 0 dBFS(峰值) ≈ 120 dB SPL
  (Knowles SPH0645:−26 dBFS、AOP 120 dB;Infineon IM69D130 同)。
- 峰值 −26 dBFS ≡ **RMS −29 dBFS**。本工程 dBFS 用 `vDSP_rmsqv`(RMS 参考),
  因此:

```
SPL ≈ dBFS(RMS) + 120~123
```

真机实测佐证:
- Faber(SoundMeter 作者)为 iPhone 5 出厂灵敏度 41.7 Pa/FS ≈ 126.4 dB/FS,
  Empa 2015 实测修正后真实满幅 ≈ 123~124 dB SPL;
- NIOSH 声级计 App 研究(Kardous & Shaw 2014/2016):合格 App 均内置
  按机型标定的名义灵敏度,实测与 1 级声级计差 ±2 dB 内;
- 早年 iPhone 3G 满幅仅 ≈105 dB(老器件),与" folklore +100 "的出处吻合。

结论:**现代 iPhone 内建麦克风 K ≈ 120~123(RMS 参考),离散 ±6 dB**。
旧默认 +93 直接让所有读数低约 30 dB —— 一个 LAeq ≈ 35 dB 的安静房间会
显示 3~8 dB,与用户观察完全一致。

### 2.2 修复

- 新默认:`CalibrationDefaults`——iOS 内建 +120、Watch +115、Mac +100、
  外接 +90(均为开箱估计,注明不确定度);
- 旧值迁移:未手动校准过(仍=93)的安装自动升到平台新默认
  (`calibrationMigratedV2` 标记,手动改过的值保留);
- 三端设置页新增**实时校准**:测量运行中显示当前读数,±0.5/±1 dB
  步进对齐参考声级计;有 94 dB/1 kHz 声校准器时直接调到显示 94;
- 设置页滑杆范围 60~110 → 80~140(+120 在旧范围外)。

### 2.3 为什么必须保留用户校准

苹果从未公布任何 dBFS↔SPL 映射,也没有 API;麦克风灵敏度按机型、
甚至按批次浮动 ±3~6 dB。任何 App(包括 NIOSH、SoundMeter)都只能:
出厂名义灵敏度(±6 dB 内)+ 用户单点校准(对齐后 ±1~2 dB)。
这是"对标商用设备"的可达路径:校准后与 2 级声级计相当
(IEC 61672 Class 2 在 1 kHz 容差 ±1.4 dB)。

## 3. C 比 A 高 6~7 dB 不是 bug

- C 计权几乎平直(20 Hz 仅 −6.2 dB),A 计权强压低频(63 Hz −26.2 dB,
  20 Hz −50.5 dB);
- 室内噪音(空调/冰箱/管道/楼下低频)含大量低频能量 → LC−LA 天然为正:
  - ≈2~3 dB:中性宽带噪声;
  - 4~10 dB:轻度低频成分(普通室内常见,与本次观察一致);
  - \>10 dB(保守 >15):显著低频噪音,工程上用作 LFN 筛查指标。
- 修复绝对标定后,A 读数回到 30~45、C 比 A 高 3~8 dB 才是正确表现;
  若 C−A > 10,配合频谱页看 200 Hz 以下占比(`lowFrequencyRatio`)。

## 4. 本次同步修复的实现缺陷

1. **dB 域平滑 → 能量域检波器**(IEC 61672):
   `emaMS += α·(ms − emaMS)`,α = 1 − exp(−Δt/τ),F=125 ms/S=1 s;
   显示值即 LAF/LAS。dB 域平均会低估脉冲、高估低谷,与标准不符。
2. **帧推进 bug**:`MeterWorker` 每 tap 只处理一次、每次只前进半窗,
   缓冲越积越多,积到上限被整块丢弃(静默丢数据)。改为 while 循环
   50% 重叠推进,时间计权的 Δt 固定为半窗时长(48 kHz 下 42.7 ms)。
3. **Leq 进核心**:DBMeter 累加计权均方值(Double),`currentLeq()`/`leqDuration`
   供长期监听直接取标准定义的等效连续声级。停止时先摘 tap、排空 meterQueue,
   再把不足一个 FFT 窗口的尾样本接入同一滤波器状态,避免最后一段能量丢失。
4. **静音语义**:计权均方值为 0 时 SPL/Leq 返回 `-∞`,不返回 0 dB;
   报告侧将非有限值显示为无有效读数。
5. **A/C 与 F/S 锁定**:测量运行中禁止切换频率/时间计权,防止同一场 Leq
   混用不同计权;需要改变时先停止再开始新测量。
6. 自检补强(`soundsense test`):绝对链路(−29 dBFS+offset123 → 94.0, A/C)、
   F/S 阶跃响应(与 1−(1−α)^k 理论差 ≤0.01 dB)、Leq 能量平均、
   白/粉噪声修正量对解析积分(≤0.4 dB)。

## 5. 已知局限与建议(达标商用设备的边界)

- **低频 bin 分辨率**:4096 点 @48 kHz → 11.7 Hz/bin。bin 中心取计权值在
  低频(计权曲线陡峭段)有量化误差;20 Hz 以下还有手持/壳体振动伪信号
  (C 计权对其几乎不衰减)。测量时把手机放稳、别握在手心。
- **蓝牙路由**:session 选项含 `.allowBluetooth`,连接蓝牙耳机时采集切到
  HFP 麦克风(自带 AGC、灵敏度完全不同),读数会跳变。精确测量请断开蓝牙,
  用有线或内建麦克风并重新校准(外接预设 +90 仅为占位)。
- **AGC**:已用 `.measurement` mode 关闭系统 AGC/高通,这是标定可用的前提;
  不要改回默认 mode。
- **量程上限**:内建麦克风满幅 ≈ 120~126 dB SPL,>110 dB 可能削顶;
  Lpeak(真峰值)未实现,报告中的"峰值"是 F 检波最大值(LAFmax)。
- 当前实现是按 IEC 曲线设计的软件计权滤波器,但未完成型式批准所需的
  全频段容差、线性度、温度/湿度、指向性和时间稳定性验证;不能声明为
  IEC Class 1/2 认证仪器。
- 4096 点 FFT 的频谱仅作显示和辅助诊断,不能反推或替代 SPL/Leq 的时域
  计权链路。
